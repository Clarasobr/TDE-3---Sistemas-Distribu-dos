# TDE-3---Sistemas-Distribuidos

##instruções de execução:

1 - Subir o ambiente Kafka e Zookeeper (usando Docker ou localmente)

2 - Instalar as dependências: pip install -r requirements.txt

3 - Em um terminal, executar o consumidor: python consumer.py

4 -  Em outro terminal, executar o produtor: python producer.py
